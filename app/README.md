# Application
React and TypeScript frontend, CodeMirror editor, local workspace storage and IndexedDB checkpoints. Cloudflare Worker integration routes live in worker/; the optional loopback companion is server.mjs.

Use npm ci, npm run build, npm test, npm run lint, npm run test:browser, and npm run test:release. See the [root guide](../README.md) and [deployment instructions](../docs/DEPLOYMENT.md).
