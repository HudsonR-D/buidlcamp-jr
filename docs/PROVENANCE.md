# Source and asset provenance
This public release is assembled from an explicit file allowlist with fresh history. The existing private project and its history are retained separately.

| Material | Origin and release treatment |
|---|---|
| BuidlCamp application and new Worker | Project-owned source supplied for this rebuild and code authored during the rebuild; released under the owner's requested MIT license. |
| Lesson/workshop/starter content | Project-owned teaching material, revised with independent explanations, source checking, scaffolds, and safety boundaries. No external course pages, certificate graphics, or institution logos are bundled. References to games and providers are descriptive and do not imply endorsement. |
| Icons | Local SVG primitives for common interface symbols. favicon.svg is the included code-brackets icon; PNG install icons are project icon derivatives. No downloaded stock art or remote fonts are included. |
| Dependency code | Installed from the npm lockfile; runtime package notices retained in THIRD_PARTY_NOTICES.md and app/public/licenses.txt. Build tools keep their own upstream terms. |
| Tests | Synthetic names, source, tokens, and transports. They are not live learner data or valid credentials. |
| External links | Official issuer and vendor sources linked from the application and source register. Linked content is not covered by the platform's MIT license. |
| Learner work | Outside the platform's blanket license. Checkpoints do not create a LICENSE file or assign permission automatically. |

Excluded: old specifications, decision/memory logs, agent instructions, legacy experiments, unrelated products, real environment files, credentials, dependencies, builds, screenshots, test artifacts, and private registration/deployment records. A lack of secret-scan findings is not proof of universal rights or absence of every secret. Revisit provenance whenever adding third-party material.
