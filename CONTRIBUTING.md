# Contributing
Use a focused pull request explaining the learner or educator problem and the resulting behavior. Run the checks in README. Use synthetic data in tests and screenshots.

Preserve stable lesson/project identifiers and schema-1 backup compatibility. Add meaningful contract or behavior tests when changing storage, imports, authorization, AI transport, or preview isolation. Keep lesson completion distinct from external credentials and educator judgments.

Support keyboard and touch, visible focus, both themes, reduced motion, readable print, and tablet layouts. Reading support is independent of age. Do not add streak pressure, rankings, advertising, unnecessary accounts, or tracking.

Document where content and assets came from and retain their permissions and licenses. Review AI-generated material for correctness, attribution, unsafe behavior, and unnecessary dependencies. Do not copy provider course content or imply partnerships. By submitting your contribution, you agree to license that contribution under this repository's MIT license, while third-party notices remain intact.

Never include .env files, keys, browser profiles, learner data, private docs, build output, node_modules, or test artifacts. Use the [private security channel](SECURITY.md) for vulnerabilities.
